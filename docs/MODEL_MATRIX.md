## How to read this table

- **Verified local run** means this repository holds at least one recipe whose public input and output were re-downloaded and matched by SHA-256. Columns prefixed **Measured** come from those files.
- **No local run** means the repository has not run this model. Spec and price columns are **vendor-published figures copied from public documentation**, not measurements, and carry no quality or speed score of any kind.
- Published spec and measured values are deliberately separate columns. A request value is a target; the measured value is what came back.

## Access constraints

- **Grok Imagine Video 1.5** (xAI, Verified local run): Served by xAI's public API; availability is subject to xAI's own regional terms. Not independently verified against every jurisdiction. Docs: https://docs.x.ai/docs/models
- **Kling 3.0 / 3.0 Turbo / 2.5 Turbo** (Kuaishou, No local run): First-party API plus many third-party aggregators. Aggregator rates differ substantially from first-party; Kuaishou is a China-based provider so cross-border access terms vary by reseller. Docs: https://kling.ai/dev/pricing
- **Luma Ray3.2 (Dream Machine API)** (Luma Labs, No local run): First-party API at api.lumalabs.ai. Pay-per-video with no subscription or minimum. Docs: https://docs.lumalabs.ai/
- **Minimax H3 Max (image-to-video)** (Atlas Cloud, Verified local run): Accessed through the Atlas Cloud aggregation API, not directly from the model vendor. Docs: https://docs.atlascloud.ai/
- **Pika 2.2 (via Fal.ai)** (Pika / Fal.ai, No local run): No direct Pika-hosted endpoint for this route; integration is against Fal.ai infrastructure. Docs: https://fal.ai/models
- **Runway Gen-4.5 / Gen-4 Turbo** (Runway, No local run): Runway developer account. Credits are billed at $0.01 each. Docs: https://docs.dev.runwayml.com/
- **Seedance 2.0 / 2.0 Fast / 2.0 Mini** (ByteDance, No local run): Consumer access via Jimeng/Dreamina in China and Dreamina internationally. API access is via Volcengine Ark and third-party resellers, and reporting on whether the first-party API is generally open is conflicting. Resellers advertise direct China access without a Volcengine enterprise account. Docs: https://www.volcengine.com/docs/
- **Sora 2 / Sora 2 Pro** (OpenAI, No local run): OpenAI platform key. Not available in all regions; OpenAI's own supported-countries list applies and changes. Docs: https://platform.openai.com/docs/guides/video-generation
- **Veo 3.1 (Lite / Fast / standard)** (Google DeepMind, No local run): Via Gemini API or Vertex AI. Regional availability and quota tiers vary; Veo 3.1 Lite is Preview. Docs: https://ai.google.dev/gemini-api/docs/video
- **Wan (open-weight releases)** (Alibaba, No local run): Open weights, self-hosted. No vendor API key and no vendor moderation layer, so the operator is responsible for access control, logging, and output review. Docs: https://github.com/Wan-Video/Wan2.2
- **Wan 3.0 (image-to-video)** (Atlas Cloud, Verified local run): Accessed through the Atlas Cloud aggregation API. Wan is also available as open weights, which this record does not cover. Docs: https://docs.atlascloud.ai/
